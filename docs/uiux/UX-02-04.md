## 첫 사용자 검수에서 요청한 보완

- 분류 드롭다운 화살표가 테두리에 붙음: 분류 셀 안에 전용 래퍼를 두고, 화살표를 오른쪽에서 12px 안쪽에 배치한다. 선택창의 오른쪽 패딩은 32px, 래퍼 최소 너비는 90px로 확보한다. 실제 선택 요소와 키보드 조작은 유지하며 화살표가 클릭을 가리지 않게 한다. 변경: `receipt-form.ts`, `src/style.css`.
- 상세 화면의 품목별 수정이 하단 수정과 같은 영수증 수정 화면으로 이동함: 품목별 버튼과 빈 열 머리글을 제거하고 하단 수정 진입점으로 정리한다. 변경: `receipt.ts`.
- 두 보완은 UX-02~04 첫 커밋에 함께 포함할 예정이며, 이 시점에 다른 UX 항목은 추가하지 않는다.

보완 후 개발 환경 검증: 기존 테스트 39개, 타입 검사를 포함한 빌드, 위 입력·저장 통합 시나리오 9개 통과. 실제 Mac 화면의 화살표 여백과 수정 버튼 정리는 추가 패치 적용 후 확인한다.

### 전체 드롭다운으로 여백 적용 확대

사용자 후속 화면에서 분류 외에 영수증 통화와 등록 화면 여행 선택의 기본 화살표도 테두리에 붙어 있음을 확인했다. `src`의 모든 select 생성 위치를 점검했으며 공통 폼 헬퍼, 품목 분류, 사진 등록 여행 선택, OCR 점검 언어 선택이 모두 `input` 클래스를 사용한다.

분류에만 적용했던 화살표를 `select.input` 공통 스타일로 옮겼다. 일반 크기와 압축 크기 모두 오른쪽 32px의 텍스트 여백과 화살표 오른쪽 12px 여백을 적용한다. 라이트·다크 테마에 맞는 화살표 색상을 지정했다. 이 규칙은 여행 폼의 통화·영수증 언어, 영수증 폼의 통화·품목 분류, 사진 등록의 여행 선택, OCR 점검의 언어 선택에 함께 적용된다. 분류의 최소 너비 90px는 유지하고 기존 분류 전용 화살표는 제거해 중복 표시를 방지한다.

변경 범위는 `src/style.css`와 이 기록 문서다. 선택 값·이벤트·저장·자동 계산 로직은 변경하지 않는다.

공통 스타일 적용 후 타입 검사를 포함한 빌드와 패치 적용 검사를 통과했다. 실제 Mac 화면의 통화·여행·언어·분류 화살표 여백은 사용자 적용 후 확인한다.
