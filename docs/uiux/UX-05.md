## 확정한 동작

부가세 영역에서 `% 입력`과 `직접 입력` 중 하나를 선택한다. 기본은 `% 입력`이다. % 입력에서만 A/B 계산 방식 토글과 비율 입력란을 보여 준다. 토글 오른쪽에는 현재 방식에 대한 짧은 설명을 작은 글씨로 표시한다. A를 기본으로 한다.

| 방식 | 짧은 이름 | 오른쪽 설명 | 총액 11,000·10% 결과 |
| --- | --- | --- | --- |
| A (기본) | 포함세액 | 총액에 포함된 부가세를 분리해요. | 1,000 |
| B | 금액의 % | 총액에 입력한 비율을 곱해요. | 1,100 |

- A는 `총액 × 비율 ÷ (100 + 비율)`, B는 `총액 × 비율 ÷ 100`으로 계산한다.
- 총액·비율·A/B·선택 통화가 바뀌면 계산 결과를 갱신한다. 원·엔은 정수, 그 외 선택 통화는 기존 화면 표시 기준에 맞춰 소수 둘째 자리까지 반올림한다.
- 비율의 기본값은 빈 값이다. 새 영수증에서 비율을 입력하지 않으면 부가세는 기존처럼 선택 사항(null)으로 남긴다. 0%는 금액 0으로 저장한다.
- 직접 입력으로 처음 바꾸면 현재 계산 금액을 채워 수정할 수 있게 한다. 직접 입력한 금액과 비율은 같은 편집 화면 안에서 방식을 오가도 각각 유지한다. 직접 입력 금액은 총액 변경으로 자동 덮어쓰지 않는다.
- 기존 영수증의 저장된 부가세는 수정 화면을 열거나 다른 내용만 저장할 때 보존한다. 비율을 입력해야 새로 계산한다. 화면에도 저장 금액 유지 안내를 표시한다. 한 번 입력한 비율을 명시적으로 지우거나 직접 금액을 비우면 부가세 없이 저장할 수 있다.
- 계산 결과만 기존 `tax` 필드에 저장한다. DB 스키마·P5 파서·P6 집계·영수증 총액은 변경하지 않는다. 입력 방식·비율·A/B는 편집 화면 안의 임시 상태다.

## 사용자 화면 검수 후 배치 보완

영수증 총액과 부가세를 나란히 표시하던 구성을 `영수증 총액 → 부가세`의 위아래 순서로 바꿨다. 부가세 안에서는 `% 입력 / 직접 입력` 라디오 그룹 오른쪽에 A/B 토글을 두고, 그 오른쪽에 기존 설명을 표시한다. 직접 입력에서는 A/B 토글과 비율 입력란을 함께 숨긴다. 계산·입력 보존·저장 로직은 유지한다.

## 롤백
