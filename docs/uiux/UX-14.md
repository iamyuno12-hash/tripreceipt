## 문제·변경

여행 총액을 나란히 비교하는 영역 다음에 여행별 분류 통계가 별도 상위 제목 없이 이어졌다. 사용자 요청으로 UX-11과 함께 구획 개선을 앞당겼다.

- 여행 간 규모 비교는 ‘여행 간 지출 비교’ 그룹으로 유지한다.
- 각 여행의 내부 분류는 ‘여행별 지출 구성’ 상위 그룹으로 묶는다. 각 여행 이름은 하위 제목으로 두고 여행 사이에 구분선과 간격을 둔다.
- 고정 바로가기의 세 번째 항목에서 이 그룹으로 이동한다. 통화 필터로 다시 그린 뒤에도 현재 그룹으로 이동한다.
- 여행별 총액·분류 금액·분류 비율·검수 제외 안내·환산 대기·여행별 CSV는 기존대로 유지한다. 검수 필요 금액이 포함되는 여행 총액과 검수 완료 품목의 분류 합계는 다를 수 있다. 집계 기준 자체를 바꾸지 않는다.

## 범위·검증

`src/ui/screens/stats.ts`와 `src/style.css`, UX-11 기록·진행 현황에 함께 반영했다. 전체/KRW/JPY/EUR의 수정 전후 금액·막대·안내·CSV 동일성, 여행별 하위 제목과 여행 사이 구분선, 빈 여행·여행 1개, 통화 변경 후 이동을 jsdom / fake-indexeddb로 확인했다. 기존 테스트 57개·타입 검사·빌드도 통과했다. 실제 화면의 구분선·간격·고정 행은 사용자 검수 대기다.

오사카 총액 13,100엔 중 검수 필요 3,800엔이 분류에서 제외되어 9,300엔인 기존 기준값을 유지했다. UX-15의 설명 중복 정리는 후속으로 남긴다.
