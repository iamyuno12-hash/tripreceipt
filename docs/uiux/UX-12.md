# UX-12 · 월별 추이 세로 막대 그래프

- 작성일: 2026-11-23 (한국 시간)
- 상태: 사용자 최종 검수 통과 (2026-11-23)
- 기준: 사용자 커밋 `68518e3`, `feature/uiux-improvements`
- 원본 메모: 5-3

## 문제·변경

월별 지출이 가로 막대로 길게 나열되어 시간 순서에 따른 높낮이 변화를 비교하기 어려웠다. 월별 추이만 SVG 세로 막대 그래프로 바꾼다.

- 기존 `expensesByMonth`가 돌려주는 1년 전 같은 달부터 이번 달까지 13개월의 계산값·시간 순서를 그대로 사용한다. 모든 달에 연도를 포함한 `YYYY.MM` 레이블을 표시한다.
- 가로축은 연도·월, 세로축은 금액이다. 통화별로 별도 그래프와 독립 축을 두고 통화 코드를 표시한다. 다른 통화의 막대 높이를 같은 금액으로 간주하지 않는다.
- 지출 0인 달도 자리를 유지하고, 막대 높이는 정확히 0으로 둔다. 0 기준선의 짧은 표시로 위치를 알린다. 모든 달이 0이어도 유효한 축과 중복되지 않는 눈금을 유지한다.
- 축 눈금은 해당 통화의 최소 금액 단위를 기준으로 정한다. 원·엔은 정수, 달러 등은 센트 단위도 구분한다. 음수 값이 들어오면 0 기준선 아래로 그리며 값 자체를 바꾸지 않는다.
- 세로축은 간결한 숫자 표기를 사용한다. 사용자 PC에서 기본 SVG title 안내가 표시되지 않는 제보에 따라, 날짜와 정확한 금액을 직접 그리는 툴팁으로 교체했다. 각 달에 마우스를 올리는 즉시 표시하고 벗어나면 숨긴다. 0인 달에도 같은 영역을 제공한다.
- 각 달에 키보드 포커스를 옮기거나 클릭해도 금액을 확인할 수 있다. Escape로 툴팁을 닫을 수 있고 초점을 잃으면 숨긴다. 각 달의 접근성 이름에도 연도·월과 정확한 금액을 제공한다. 툴팁은 마우스 입력을 가로채지 않고 그래프 안에 배치한다.
- 사용자 요청으로 ‘월별 금액 보기’ 아코디언과 금액 표를 제거했다. PC에서 hover로 확인하는 흐름을 기본으로 한다.
- UX-13 후속 요청에 따라 통계 본문의 가용 폭을 사용하고 월별 가로축도 그 영역에 맞춘다. 초기 960px 최소 폭과 고정 viewBox를 제거하고 가로 좌표를 비율로 배치한다. 높이 220px와 글자 크기는 유지해 너비가 커져도 세로와 글자가 함께 늘어나지 않는다.
- PC에서 모든 달이 그래프 프레임 안에 맞도록 양쪽 여백과 연도·월 레이블을 유지한다. 툴팁도 실제 그래프 너비를 기준으로 배치한다. 키보드 접근과 밝은/어두운 테마의 기존 색을 유지한다.
- 통화 필터, 혼합 통화의 고정 환산, 검수·환산 대기 제외 기준, 여행 비교·분류, 고정 바로가기, 상단 전체 CSV와 여행별 CSV는 유지한다.

## 범위·완료 조건

- `src/ui/monthly-chart.ts`: 세로 막대·통화별 눈금·연도/월·직접 표시하는 금액 툴팁.
- `src/ui/screens/stats.ts`: 월별 가로 막대 표시를 새 차트로 교체.
- `src/style.css`: SVG·축·툴팁 스타일과 가로 폭 연동·고정 높이.
- 이 문서와 `PROGRESS.md`: 검증·판정·다음 작업.

집계·환율·저장소·상태·CSV 생성 코드는 변경하지 않는다. 완료 조건은 같은 월별 계산값이 시간 순서대로 세로 막대에 나타나고, 0인 달·연도 경계·통화 단위가 올바르며 기존 화면 동작이 유지되는 것이다.

## 개발 환경 검증

- 기존 자동 테스트 57개, 빌드에 포함된 타입 검사·프로덕션 빌드·공백 검사 통과.
- jsdom / fake-indexeddb에서 초기 세로 그래프·수정 전 금액 대조·축·필터·CSV 시나리오 11개 통과 후, 이번 hover·키보드·크기·아코디언 제거·데이터 대조·CSV 후속 시나리오 9개를 검증했다. 초기 검증은 실제 PC의 기본 SVG 툴팁 표시를 보장하지 않았으며 사용자 제보를 반영해 직접 표시 방식으로 수정했다.
- UX-11/14의 가로 막대와 초기 세로 그래프의 전체/KRW/JPY 값이 같았고, 이번 후속에서도 직전 차트 모듈을 별도로 고정해 월별 값과 여행 비교·분류·환산 대기 안내를 대조했다. 금액과 순서는 동일했다.
- 2026-11-23 기준 2025.11부터 2026.11까지 13개월, 2025.12→2026.01 연도 경계와 월 순서를 확인했다.
- 제주 221,000원, 오사카 총액 13,100엔 중 검수 필요 3,800엔을 제외한 월별 9,300엔, 기간 밖 오이도 12,700원 제외를 유지했다.
- 100:50:0의 막대 높이 비율, 모든 달이 0인 경우, 빈 데이터, USD 0.01/0.02, 양수/음수의 0 기준선 위치를 확인했다. 0인 달에 거짓 양수 높이나 NaN/Infinity가 없었다.
- USD 10·고정 환율 1400의 KRW 14,000 반영과 환산 대기 제외, 필터 전환 시 원본 DB·환율·네트워크 불변을 확인했다.
- JPY 필터 중 전체·여행 CSV의 파일명과 UTF-8 BOM을 포함한 바이트가 기존 결과와 같았다.
- 세 고정 바로가기의 현재 제목 이동·포커스·이동 여백, 그래프 스크롤 영역의 키보드 접근과 스타일을 확인했다.
- pointerenter 직후 툴팁의 visible 상태·월·금액, pointerleave 숨김, 다른 달 이동 시 갱신, 0원·센트·음수, 키보드 포커스·클릭·Escape·blur를 확인했다. 첫/마지막 달과 긴 달러 금액의 배치를 확인했다. 글자 폭 측정은 모의 환경임을 구분한다.
- 초기 폭 조정에서는 달 간격 확대와 높이 220px를 확인했다. 이후 사용자 요청으로 가용 폭에 맞추는 방식으로 재조정했으며 UX-13 후속 검증에 기록했다. 아코디언·금액 표 제거와 툴팁 초기화는 유지한다.
- 새 툴팁·낮아진 높이는 아래 사용자 최종 판정으로 통과했다. UX-13에서 추가한 가용 폭 연동·프레임 맞춤·너비별 툴팁의 실제 Mac 검수는 해당 문서에서 관리한다. 모의 DOM 검증을 실제 브라우저 시각 검증으로 간주하지 않는다.

## 사용자 검수

1. 월별 추이가 세로 막대로 나오고 0원인 달도 연도·월 레이블이 유지되는지 확인한다.
2. KRW/JPY 등 통화를 바꾸어 통화별 그래프와 기존 금액이 맞는지 확인한다. 막대와 0원인 달에 마우스를 올려 날짜·정확한 금액이 바로 뜨는지 확인한다. 키보드 포커스로도 확인할 수 있어야 한다.
3. 넓어진 통계 영역 안에 모든 달이 여백을 남겨 맞고 높이 220px를 유지하는지 확인한다. 고정 바로가기와 툴팁은 정상이어야 하고 ‘월별 금액 보기’는 없어야 한다.
