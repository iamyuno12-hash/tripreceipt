## 문제와 변경

수정 화면에는 OCR 글자만 있어 입력값과 사진을 대조하려면 상세 화면으로 나가야 했다. 사진이 저장된 영수증의 수정 화면에 `영수증 사진 보기` 패널을 추가한다. 어느 진입 경로든 처음에는 펼친 상태로 사진을 불러오며, OCR 글자는 접힌 상태로 시작한다. 기존 OCR 글자와 입력 폼을 함께 유지한다.

`화면 맞춤`, `100%`, 확대·축소 버튼을 제공하고 사진 영역 안에서 스크롤할 수 있다. 기본은 사진 전체가 보이도록 맞추며, 100%는 저장된 이미지의 실제 크기로 표시한다. 사진 조작·접기·재열기는 입력 폼을 다시 만들거나 저장하지 않으므로 미저장 입력값을 보존한다.

사진은 상세 화면과 동일한 IndexedDB 저장본이다. 현재 P3는 카메라 원본 대신 OCR에 사용한 처리 이미지를 저장하므로, 이 작업도 그 저장본을 보여 준다. 새 사진 업로드·OCR 재실행·저장 구조 변경은 포함하지 않는다.

사진이 없는 영수증은 기존 수정 화면을 유지한다. 사진 키는 있으나 저장본이 없거나 표시 중 오류가 나면 안내를 보여 주고 OCR 글자·폼은 계속 사용할 수 있다.

## 사용자 Mac에서 확인할 것

1. 사진이 있는 영수증의 수정 화면에 들어가면 `영수증 사진 보기`는 펼쳐져 있고 OCR 글자는 접혀 있는지 확인한다. 상세 화면과 같은 사진과 기존 OCR 글자가 함께 있는지 확인한다.
2. `100%`, 확대·축소·스크롤·화면 맞춤을 사용해 사진을 읽기 편하게 볼 수 있는지 확인한다.
3. 상호나 품목을 입력한 뒤 사진을 접었다 펼쳐도 입력값이 유지되는지 확인한다. 저장 후에도 기존 사진 연결이 유지되는지 확인한다.
4. 사진 없는 직접 입력 영수증의 수정 화면도 정상인지 확인한다.
