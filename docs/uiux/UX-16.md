## 화면·동선

| 위치 | 최종 동작 |
| --- | --- |
| 주요 메뉴 | 여행 · 통계 · 설정. 사진 등록·직접 입력·영수증 상세/수정에서도 여행 메뉴 활성화 |
| 여행 상단 | 초록색 ‘+ 여행 추가’를 먼저 두고, 보조 ‘+ 영수증 등록’을 뒤에 배치 |
| 공통 등록 창 | 여행(미지정 포함)과 사진/직접 입력을 선택. ‘계속’은 입력 화면으로만 이동하며 영수증을 만들지 않음 |
| 여행 미지정 | 실제 여행과 별도의 보관함. 0장이어도 위쪽에 표시하고 펼쳐서 조회 |
| 여행별 목록 | 카드 일반 클릭은 별도 여행 상세로 이동. 화살표를 포함한 ‘영수증 n장’ 버튼만 인라인 목록을 펼침/접음 |
| 여행 관리 | 여행 요약 우측 상단의 무채색 배경 수정·삭제 버튼. 삭제 글자는 빨간색 |
| 여행 안의 등록 | 같은 등록 창을 열되 해당 여행을 미리 선택 |
| 영수증 수정 | 여행을 지정·변경하거나 다시 미지정으로 보관 가능. 저장 전 선택은 기존 영수증에 반영하지 않음 |
| 상세에서 복귀 | 영수증을 연 홈/여행 상세 각각의 원래 화면·스크롤·초점으로 복원 |
| 이용 순서 | 샘플 안내 위(샘플이 없으면 같은 최상단 자리)에 한 줄로 고정. 우측 원형 물음표 아이콘 hover로 저장·검수·집계 안내 표시 |

여러 여행을 함께 펼칠 수 있다. 장수 버튼을 직접 눌렀을 때만 펼침 상태를 바꾸고, 해당 탭에서 직접 선택한 상태만 유지한다. 주소 진입·여행 상세 방문·미지정 상세 방문은 홈의 여행을 자동으로 펼치지 않는다. 카드 일반 클릭과 관리 버튼은 장수 버튼의 펼침 동작과 분리한다.

## 저장·OCR·환산

- 여행 미지정은 `Receipt.tripId: null`로 저장한다. 실제 여행 레코드를 만들지 않으며, 기존 여행 ID·영수증 ID·사진·OCR 원문을 유지한다. DB 버전과 스토어는 그대로다. IndexedDB에서 null은 인덱스 키가 아니므로 보관함 조회는 전체 영수증 중 null을 고른다.
- 미지정 사진 등록은 결제 통화와 OCR 인식 언어를 선택할 수 있다. 여행을 골랐으면 여행의 기본 통화·인식 언어를 가져온다. 실제 결제 통화는 수정 화면에서 별도로 바꿀 수 있다. 사용자가 고른 인식 언어는 통화 변경으로 임의로 바꾸지 않는다.
- 사진·OCR 저장 → 영수증 수정 → 내용 저장의 기존 구분을 유지한다. ‘저장하고 내용 입력’에서 사진·OCR 원문과 인식 대기 영수증을 저장한다. 수정 화면은 사진을 펼치고 OCR 원문은 접어 둔다. OCR 결과 반영 기능도 유지한다.
- 처리·저장 중에는 여행·통화·언어 변경을 막는다. 인식 결과가 있는 상태에서 다른 인식 언어를 선택하면 사진을 다시 선택하게 한다. 같은 OCR 결과의 저장 중복을 막고, 삭제된 여행을 저장 대상으로 선택했으면 실패를 알리며 새로 만든 미저장 사진은 회수한다.
- 영수증 생성·이동은 여행 존재 여부와 저장을 같은 트랜잭션에서 확인한다. 삭제된 여행으로 이동하려는 경우 기존 내용은 보존한다.
- 여행 지정·변경·해제는 실제 내용 변경으로 취급하여 기존 확인됨을 다시 판정한다. 같은 여행·내용을 그대로 저장하면 확인됨은 유지한다. 원래 금액·통화·품목·사진·OCR 원문은 이동 과정에서 보존한다.
- 환산 입력 영역은 현재 선택한 여행의 기준 통화에 맞춰 갱신된다. 미지정이면 환산 영역을 숨기고 자동 환율 조회·저장을 하지 않는다. 다른 여행으로 바꾸는 동안 수동 입력한 환율과 기존 고정값을 보존하며, 늦게 끝난 이전 통화의 응답이 새 입력을 덮어쓰지 않게 한다.

## 집계·CSV

- 여행 미지정은 여행별 총지출·월별 추이·여행 비교·분류 통계에서 제외한다. 여행 지정 후에는 기존 상태·환산 규칙으로 집계한다.
- 전체 CSV에는 미지정 영수증도 포함한다. 여행명은 ‘여행 미지정’, 여행 ID·집계 기준 통화·환산값은 빈칸, 통계 집계 포함은 ‘아니요’, 환산 상태는 ‘여행 미지정’이다. 원래 결제 통화·금액·품목·세금·확인 상태는 보존한다.
- 기존 여행의 CSV 열·값·BOM·첫 품목 행에만 총액/세금을 기록하는 방식은 유지한다. 개별 여행 CSV에는 해당 여행의 영수증만 포함한다.
- 등록 여행이 없어도 통계 화면에서 전체 CSV를 내려받을 수 있다. 미지정은 여행에 지정한 뒤 통계에 포함된다는 안내를 둔다.

## 기존 주소·복귀

- `#/`, `#/trips/:id`, 여행 생성/수정, 영수증 생성/상세/수정, `#/scan`, 통계·설정 주소는 유지한다. 기존 여행 상세 주소는 여행 이름·기간·총지출·영수증 장수·수정/삭제·영수증 목록을 갖춘 별도 상세 화면으로 연다.
- `#/unassigned`(별도 보관함 상세)와 `#/receipts/new`를 추가한다. 공통 등록 창의 여행·통화·언어 선택은 해시 경로의 쿼리로 입력 화면에 전달하며, 경로 ID가 쿼리보다 우선한다.
- 기존 `#/scan`은 등록 여행이 있으면 기존처럼 최근 여행을 기본 선택한다. 새 공통 등록 창은 선택값을 명시적으로 전달하므로 미지정 선택도 그대로 이어진다.
- 라우터가 화면을 붙인 뒤 복귀 위치를 복원한다. 홈에서 연 영수증은 홈으로, 여행 상세에서 연 영수증은 해당 상세로 복귀한다. 여행을 옮겼으면 새 여행의 별도 상세로 연결하고 홈 목록을 자동으로 펼치지 않는다. 펼침/스크롤 상태는 탭 안에서만 보관하며 영수증 데이터나 설정에 저장하지 않는다.

## 사용자 검수

1. 여행·통계·설정 메뉴, 여행 요약·수정/빨간 삭제, 영수증 펼침/접힘을 확인한다.
2. 상단 등록에서 여행을 고른 뒤 사진/직접 입력으로 각각 진입한다. 여행 안의 등록은 해당 여행을 미리 선택해야 한다.
3. 미지정으로 영수증을 저장하고, 상세·수정에서 조회한 뒤 여행을 지정한다. 저장한 여행에서 나타나는지, 다시 미지정으로도 옮길 수 있는지 확인한다.
4. 사진 등록 후 수정 화면의 사진 펼침/OCR 접힘·OCR 결과 반영·내용 저장을 확인한다.
5. 목록을 스크롤한 상태에서 영수증을 보고 돌아와 펼침 상태와 위치를 확인한다. 실제 데이터로 삭제를 시험할 필요는 없으며 삭제 확인 취소만으로도 버튼 구분을 확인할 수 있다.
6. 기존 통계·필터·CSV를 확인한다. 미지정 원본은 전체 CSV에 포함되고 통계에서는 빠져야 한다.

## 사용자 후속: 별도 상세 복원·장수 버튼·상단 안내

2026-11-23 사용자 피드백에 따라 초기 통합 시안에서 없앴던 별도 여행 상세를 복원했다. 카드 전체에 걸린 상세 링크와 실제 장수 버튼을 분리했으며, 바깥 화살표·summary 전체 펼침·주소 진입 시 자동 펼침은 제거했다. 펼침 화살표는 장수 버튼 내부에서 상태에 맞춰 바뀐다. 수정·삭제·등록 버튼은 각자의 동작을 유지한다.

이용 순서의 기본 표시는 ‘이용 순서 영수증 등록 → 여행·입력 방식 선택 → 내용 확인·저장 → 통계’ 한 줄이다. 기존 아코디언 안내는 없애고, 우측 원형 물음표 아이콘에 마우스를 올리면 상세 안내가 보이도록 했다. 클릭·키보드 초점으로 툴팁을 고정하지 않는다. 안내는 홈·여행 상세·미지정 상세·사진 등록의 상단에서 같은 방식으로 표시한다. 통계 자체의 집계 안내는 별도 컴포넌트로 유지한다.

후속 검증: 자동 테스트 66개·타입 검사/빌드 통과. 가상 DOM에서 새 클릭 분리, 장수 버튼만 펼침, 별도 상세/미지정 상세, 등록 위치, 목록/상세 각각의 스크롤과 초점 복귀, 주소 이동 시 자동 펼침 없음, 기존 집계·CSV를 포함한 10개 시나리오가 통과했다. 고정 위치·기본 숨김·hover 선택자의 표시/숨김은 CSS와 모의 hover 스타일로 확인했다. 실제 마우스 hover와 카드 영역의 클릭 위치·픽셀 배치는 Mac에서 확인한다. 초기 시안의 화면 검증 기록은 이 후속의 화면 구성으로 갱신한다.

추가 검수: 여행 추가의 순서/초록 강조 → 고정 이용 순서와 hover → 카드 일반 클릭의 별도 상세 → 장수 버튼의 펼침/접힘 → 목록 위 등록 → 홈/상세 각각의 영수증 복귀 동선을 확인한다.

## 사용자 후속: 물음표 아이콘

이용 순서 우측 끝에 원형 물음표 버튼을 두고, 상세 안내의 hover 시작 영역을 이 아이콘으로 한정했다. 아이콘에서 안내로 이동할 때는 열린 상태를 유지하고, 벗어나면 닫힌다. 이용 순서 문장·고정 위치·기존 상태별 안내 내용은 유지한다. 가상 DOM에서 기본 숨김·아이콘 hover 표시·해제 후 숨김·클릭과 초점으로 고정되지 않음·기존 안내 내용 보존을 확인하고 타입 검사를 통과했다. 실제 마우스 이동과 배치는 사용자 Mac에서 확인한다.

## 롤백

새 미지정 영수증을 만들지 않았다면 패치를 역적용하거나 확정 커밋을 `git revert`한다. 미지정 영수증을 만든 뒤 이전 코드로 돌아가려면 현재 버전에서 그 영수증들을 먼저 여행에 지정한다. 이전 화면은 null 여행을 지원하지 않는다. Git 롤백은 IndexedDB 내용을 되돌리지 않으며 CSV에는 사진이 포함되지 않는다.

2026-11-23 사용자 최종 확인: 통과. 여행·등록 통합, 미지정 보관함, 별도 여행 상세, 장수 버튼 펼침, 등록 위치와 우측 물음표 hover 안내를 포함한 UX-16을 확정한다. 앞선 사용자 검수 대기 기록은 이 판정으로 종료하며, 커밋은 이 문서를 포함하는 Git 이력으로 확인한다.

## 영수증 등록 흐름 후속

2026-11-23 UI/UX 담당자가 P5/P6과 현 버전을 나란히 열고 같은 영수증으로 등록 과정을 비교했다. 여행 상세의 두 직접 진입 버튼을 다시 살리고, 이미 정한 여행을 재선택하는 문제와 미지정 등록의 결제 통화 중복을 발견했다. 사진마다 영수증에 적힌 언어를 고를 수 있도록 OCR 언어 선택 시점을 정했고, 사진 등록과 품목·금액 저장의 차이가 버튼 이름에 드러나도록 문구를 제안했다. 이 설계를 바탕으로 Codex와 화면을 수정했다.

- 여행 목록의 등록 버튼은 상단 ‘+ 영수증 등록’ 한 곳에 둔다. 등록 창에서는 여행과 입력 방식만 고른다. 펼친 카드에서는 기존 영수증을 확인하고, 여행 상세와 미지정 보관함 상세에서는 ‘사진으로 등록’, ‘직접 입력’으로 바로 들어갈 수 있다.
- 여행 목록에서 펼친 미지정 영수증 영역은 카드 상단보다 밝은 웜그레이로 일반 목록과 구분한다. 통계·CSV 안내는 별표를 붙인 작은 글씨로 표시한다.
- 사진 등록 화면에서 파일을 고르기 전에 OCR 언어를 선택한다. 여행에 지정한 언어를 우선 쓰고, 지정된 언어가 없으면 여행 통화에 따른 언어를 제안한다. 미지정 기본 언어는 한국어(영어 포함)다. 이미 고른 사진은 언어를 바꾸면 다시 읽는다.
- 소속 여행은 등록·추가·수정 화면의 제목 아래에 표시한다. 영수증 상세 오른쪽의 ‘여행 변경’은 연한 테두리와 차분한 글씨로 표시하고, 미지정 영수증의 ‘여행 지정’에는 옅은 웜그레이 배경을 더한다. 결제 통화는 추가·수정 화면에서 선택하며, 새 영수증의 기본값은 여행 통화 또는 미지정의 KRW다.
- ‘등록하고 내용 입력’은 사진과 OCR 원문을 인식 대기 상태로 등록한다. 품목·금액은 다음 수정 화면에서 저장한다.

검증은 자동 테스트 66개와 프로덕션 빌드를 통과했다. 모의 OCR로 홈·상세·미지정 진입, 사진별 언어 선택과 재인식, 인식 대기 재진입, 결제 통화 변경, 여행 변경 및 취소를 확인했다.
