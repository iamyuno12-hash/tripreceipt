# UX-11 · 통계 그룹·상단 CSV·고정 바로가기

- 작성일: 2026-11-23 (한국 시간)
- 상태: 사용자 최종 검수 통과 (2026-11-23)

- 원본 메모: 5-2

## 문제와 변경

월별 추이·여행 비교·여행별 분류가 연속해서 나열되고, 전체 CSV 버튼이 표시 통화와 그래프 사이에 있어 역할을 구별하기 어려웠다.

- 월별 추이와 여행 비교를 각각 제목·짧은 목적 설명·구분선·바깥 테두리·간격이 있는 독립 영역으로 나눈다. 월별은 시간에 따른 흐름, 여행 비교는 여행별 지출 규모를 보여준다는 점을 구분한다.
- 월별 제목은 ‘월별 지출 추이’로 줄이고, 기존 ‘1년 전부터 이번 달까지’ 기간은 바로 아래 목적 설명으로 옮긴다. 기존 13개월의 계산 범위는 그대로다.
- 사용자 후속 요청으로 ‘여행별 지출 구성’을 세 번째 그룹으로 묶었다. 여행 이름은 그룹 안의 하위 제목으로 두고, 여행 사이에 구분선과 간격을 둔다. 이 구획은 UX-14를 함께 구현한 것으로 기록한다.
- 상단 ‘바로가기’의 월별 추이·여행 비교·여행별 지출 구성 버튼은 해당 영역으로 스크롤하고 제목에 키보드 포커스를 옮긴다. 해시 라우터의 주소와 표시 통화는 유지한다. 통화 변경으로 그래프를 다시 그린 뒤에도 현재 제목으로 이동한다.
- 바로가기 행만 `position: sticky; top: 0`으로 고정한다. 처음에는 원래 위치에 있고, 상단에 닿으면 붙어 유지되며 위로 돌아와 원래 위치에 도달하면 자연스럽게 풀린다. CSV·통화 선택·결과 수는 고정하지 않는다. 바로가기 행에는 불투명한 페이지 배경을 적용한다.
- 바로가기를 누를 때 실제 행 높이를 재어 대상 영역의 이동 여백에 반영한다. 좁은 화면에서 행이 줄바꿈되어도 제목이 고정된 행에 가리지 않도록 한다.
- 전체 CSV는 통계 제목 바로 아래에 버튼과 작은 설명만 배치한다. 독립 CSV 그룹·제목·CSV 바로가기는 제거한다. 전체 여행 범위와 사진 미포함을 안내한다. 통화 선택과 관계없이 전체 CSV를 내보내고, 여행별 CSV는 해당 여행만 내보내는 기존 동작을 유지한다.
- 영역 배경은 일반 표면 색, 테두리는 청회색 계열의 기존 구조용 색을 사용한다. 상태 태그의 초록·주황 배경을 영역 강조에 사용하지 않는다. 밝은/어두운 테마 변수를 따르고 좁은 화면에서는 패딩을 줄인다.
- 여행 없음·여행 1개·지출 없음에서도 기존 안내를 유지한다. 여행이 없으면 이동 대상과 내보내기 버튼을 만들지 않는다.

## 변경 범위·완료 조건

- `src/ui/screens/stats.ts`: 세 그룹의 제목·영역·바로가기, 전체 CSV 위치, 이동 여백.
- `src/style.css`: 통계 영역·제목·간격·여행 구분선·고정 바로가기·좁은 화면 스타일.
- 이 문서와 `UX-14.md`, `PROGRESS.md`: 검증 결과와 다음 작업.

집계·환율·검수 상태·CSV 생성·저장소·라우팅 코드는 변경하지 않는다. 통화 필터는 UX-10 동작을 유지한다. UX-14 구획은 이번 사용자 요청에 따라 앞당겨 함께 구현했다. 그래프 방향(UX-12), 여행 비교 검색·기간 필터(UX-13), 집계 설명 중복 정리(UX-15)는 후속 작업이다.

완료 조건은 세 그룹의 목적과 경계가 명확하고, 바로가기 행만 스크롤에 따라 고정·해제되며 현재 그룹으로 이동하고, 상단 전체 CSV 버튼의 범위가 명확한 것이다. 계산값과 CSV 내용은 기존과 같아야 한다.

## 개발 환경 검증

- 자동 테스트 57개 통과, 프로덕션 빌드에 포함된 타입 검사와 빌드 통과, 공백 검사 통과.
- jsdom / fake-indexeddb에서 UX-10 통화 필터 시나리오 10개와 이번 후속의 그룹·고정 스타일·이동 여백·수정 전 화면 대조·CSV 시나리오 9개 통과.
- 직전 UX-11 화면과 전체/KRW/JPY/EUR 필터별 그래프 내용·여행별 통계·환산 대기·빈 여행 결과를 대조해 동일함을 확인했다.
- 제주 221,000원, 오사카 총액 13,100엔 / 검수 필요 3,800엔을 제외한 분류·월별 합계 9,300엔, 기간 밖 오이도 12,700원 회귀값을 유지했다. 외화 영수증의 고정 환산액도 유지했다.
- 세 바로가기의 대상 영역·스크롤 호출·제목 포커스, 통화 변경 후 새 제목으로 이동, 주소·선택 통화·DB·네트워크 불변을 확인했다. 단일 행과 줄바꿈 상황의 높이를 모의 입력해 이동 여백을 확인했다.
- 바로가기 행만 sticky/top/배경을 갖는 계산 스타일과 여행 간 구분선 적용을 확인했다. 실제 고정·해제 위치와 시각적 배치는 모의 DOM에서 검증할 수 없으므로 사용자 화면 검수 대상으로 둔다.
- JPY 선택 중에도 전체 CSV와 여행별 CSV가 기존 생성 결과와 UTF-8 BOM을 포함한 바이트 단위로 같고 파일명이 같음을 확인했다. 그래프 바로가기는 다운로드를 실행하지 않는다.
- 여행 없음·여행 1개·지출 없음의 안내와 이동 대상을 확인했다.
- 실제 Mac 화면 배치·스크롤 위치·테마와 다운로드 파일 열기는 사용자 검수 대기다.

## 사용자 검수

1. 월별 추이·여행 비교·여행별 지출 구성이 세 그룹으로 구분되고 마지막 그룹의 여행 사이에 구분선이 있는지 확인한다.
2. 제목 바로 아래 전체 CSV 버튼과 작은 설명이 있고, 별도의 CSV 그룹이 없는지 확인한다. 선택 통화와 관계없이 모든 여행을 내보내야 한다.
3. 아래로 스크롤해 바로가기 행이 상단에 닿으면 그 행만 고정되는지, 위로 돌아오면 원래 위치로 자연스럽게 풀리고 위쪽 내용이 다시 보이는지 확인한다.
4. 세 바로가기의 이동 위치에서 제목이 고정 행에 가리지 않는지 확인한다. 통화를 바꾼 뒤에도 이동이 되고 선택 통화가 유지되어야 한다. 기존 금액과 여행별 CSV도 유지되어야 한다.
