## 문제·변경

여행 비교 목록에서 필요한 여행을 찾고, 같은 여행들의 분류 구성도 함께 확인해야 한다. 사용자 후속 요청에 따라 비교 전용이던 조건을 두 여행 통계의 공통 조건으로 바꾸고, 통계 본문의 너비와 월별 그래프도 함께 조정한다.

- 기간은 1년(기본) / 3개월 / 1개월 / 전체 기간 순서다. 화면을 열었을 때의 현지 날짜까지 달력의 월·연도를 기준으로 계산하며 양끝을 포함한다. 2026-11-23 기준 1년은 2025-11-23~2026-11-23, 3개월은 2026-08-23~2026-11-23, 1개월은 2026-10-23~2026-11-23이다.
- 여행 기간이 선택 기간과 겹치면 표시한다. 시작일이 오래전이어도 기간에 걸치는 장기 여행은 포함한다. 미래에 시작하는 여행은 최근 기간에서 빠지고 전체 기간에서는 표시한다. 이전 달에 같은 일자가 없으면 그 달의 말일로 맞춘다.
- 이름 부분 검색은 앞뒤 공백·영문 대소문자·한글 정규화 차이를 구분하지 않는다. 기간과 이름은 ‘여행 간 지출 비교’와 ‘여행별 지출 구성’에 함께 적용한다. 두 영역은 같은 여행 집합을 사용한다.
- 큰 ‘여행별 지출’ 그룹 맨 위에 공통 필터·조건 해제·날짜 범위·선택 수를 둔다. 그 아래 요약 성격의 비교는 배경이 다른 청회색 내부 카드로, 분류 구성은 구분선 아래 하위 영역으로 둔다. 여행 사이 구분선은 유지한다.
- ‘조건 해제’는 전체 기간·빈 이름으로 되돌리고 전역 표시 통화는 유지한다. 전역 통화를 바꿔도 공통 기간·이름은 유지한다. 화면에 새로 진입하면 1년·빈 이름으로 시작한다. 선택 조건은 저장소에 기록하지 않는다.
- 비교 결과의 최대 480px 내부 세로 스크롤과 키보드 접근은 유지한다. 조건을 바꾸면 비교 결과의 내부 스크롤은 처음으로 돌린다. 결과 없음 안내는 두 영역에 표시한다.
- 여행이 1개여도 공통 필터는 분류 구성에 적용한다. 비교 카드의 ‘2개 이상 등록’ 안내는 유지한다.
- 통계 화면의 본문 최대 너비는 1080px로 둔다. 초기의 제한 없는 전체 폭이 너무 넓다는 후속 피드백을 반영했으며, 기존 760px보다는 여유 있게 사용한다. 화면 가장자리와 그룹 안쪽 패딩은 유지하고 다른 화면의 너비는 바꾸지 않는다.
- 월별 SVG의 고정 최소 폭을 제거한다. 가로축·월 위치·막대 폭은 영역 너비의 비율로 배치하고 양쪽 여백을 둔다. 세로 220px와 글자 크기는 유지해 가로로 넓어져도 세로·글자가 함께 늘어나지 않는다. PC에서 13개월이 프레임 안에 맞게 배치된다.
- 월별 금액·순서·0원 표시·직접 표시 툴팁과 금액 아코디언 제거는 유지한다. 툴팁은 실제 그래프 폭에 맞춰 가장자리 안에 배치한다.

## 집계·필터의 의미

**기간·이름은 두 여행 통계의 표시 대상을 고르는 공통 조건이다. 영수증 결제일로 금액을 잘라 다시 계산하지 않는다.** 선택 여행의 전체 금액·고정 환산·상태별 집계 기준은 유지한다. 비교 막대의 길이는 현재 결과의 같은 통화 최댓값 기준이며 금액 큰 순서로 정렬한다.

비교 금액은 검수 완료 지출이고, 분류 영역의 여행 총액에는 검수 전 금액이 포함될 수 있다. 오사카의 비교 9,300엔과 분류 영역 총액 13,100엔의 차이는 그대로 보존한다. 분류 막대 합계는 9,300엔이다.

원본 영수증·확인 상태·환율·DB를 쓰거나 환율을 다시 조회하지 않는다. 월별 추이에는 여행 기간·이름 조건을 적용하지 않고 전역 통화만 적용한다. 전체 CSV는 모든 여행을, 여행별 CSV는 해당 여행의 전체 데이터를 내보내는 기존 범위를 유지한다.

## 변경 범위·완료 조건

- `src/ui/trip-comparison.ts`: 두 영역의 공통 필터·큰 그룹·비교 카드·공유 결과 갱신.
- `src/ui/screens/stats.ts`: 공통 조건 연결·분류 결과·제목 위계·통화 전환 사이 조건 유지.
- `src/ui/monthly-chart.ts`: 가로 비율 좌표·실제 폭 기준 툴팁.
- `src/style.css`: 통계 너비·공통 컨트롤·요약 카드·결과 높이·그래프 프레임.
- 이 문서와 `UX-12.md`, `PROGRESS.md`: 후속 지정·검증·판정.

집계·환율·상태·저장소·CSV 생성 코드는 변경하지 않는다. 완료 조건은 두 여행 영역의 대상이 함께 바뀌고, 필터의 상위 소속과 내부 요약 카드가 명확하며, 통계와 월별 그래프가 가용 너비에 맞고 기존 금액이 보존되는 것이다.

## 개발 환경 검증

- 기존 자동 테스트 57개·빌드에 포함된 타입 검사·프로덕션 빌드·공백 검사 통과.
- 초기 비교 전용 조건 12개 시나리오 이후 사용자 지정을 반영하여, 공통 필터·그룹·금액·화면 폭·그래프·CSV 최종 시나리오 11개가 jsdom / fake-indexeddb에서 통과했다.
- 1개월·3개월·1년의 경계 양끝·경계 하루 전·장기 여행·미래 여행을 두 영역에 함께 적용했다. 달력의 3개월/1개월 단위는 일수 환산으로 대체하지 않는다.
- 조건 해제 후 직전 비교 화면과 전체 여행의 금액·정렬·막대 비율을 대조했다. 원래 분류 총액·검수 제외·고정 환산·환산 대기도 유지했다.
- 이름 검색·공백·대소문자·한글 NFC/NFD·빈 결과·입력 포커스·공통 조건 해제, 통화 변경 시 두 영역의 조건 유지를 확인했다.
- 통계에만 본문 최대 너비 조정 스타일이 적용되고 다른 화면은 760px 상한을 유지함을 확인했다. 최종 1080px 상한·1년 기본값·새 진입과 통화 변경·그래프 맞춤은 추가 모의 DOM 확인 4건과 타입 검사로 확인했다. SVG는 고정 viewBox/최소 폭 대신 가로 비율 좌표를 사용한다. 640/960/1440px의 모의 폭에서 막대·축 여백·툴팁 경계를 확인했다. 실제 픽셀 배치와 글자 가독성은 Mac 검수 대상이다.
- 2026-05-31의 3개월 전은 2026-02-28, 2024-03-31의 1개월 전은 2024-02-29로 맞추고 경계 날짜를 포함함을 확인했다.
- 월별 그래프·금액·고정 바로가기·전체/여행 CSV·DB·네트워크·주소가 유지됨을 확인했다. 전체/여행 CSV는 기존 파일명과 UTF-8 BOM 포함 바이트를 유지했다.

## 사용자 검수

1. 기간 옵션이 1년(기본)·3개월·1개월·전체 기간이고, 필터가 큰 여행 통계 그룹의 위쪽에 있는지 확인한다.
2. 기간·이름을 바꾸어 비교와 분류가 같은 여행들로 함께 바뀌는지, 조건 해제와 전역 통화 변경도 정상인지 확인한다.
3. 비교가 배경색이 다른 내부 요약 카드이고 분류가 그 아래 구분되어 있는지 확인한다. 기존 금액은 유지되어야 한다.
4. 통계가 최대 1080px 안에서 적당한 너비를 쓰고, 월별 그래프의 모든 달이 테두리 안쪽 여백을 남겨 맞는지 확인한다. 창 크기를 바꿔도 220px 높이·툴팁·고정 바로가기를 유지해야 한다.
